# chzzk-tts

치지직(Chzzk) 채팅을 TTS 서비스를 이용하여 읽어주는 프로그램입니다.

## 실행 방법

### 요구사항
- Python 3.12+
- uv 패키지 관리자

### 설치 및 실행

```bash
# 의존성 설치
uv sync

# 실행
uv run python main.py
```

또는 가상환경을 활성화 후 실행:

```bash
# Windows
.venv\Scripts\activate
python main.py

# Unix/Mac
source .venv/bin/activate
python main.py
```

## 크레딧

이 프로젝트는 [sugial/TwitchTTS](https://github.com/sugial/TwitchTTS)의 초기 코드베이스를 기반으로 시작되었습니다.
